# Описание классов проекта

Ниже кратко описано, за что отвечает каждый класс в проекте.

## Корневой пакет

- `Main` — точка входа: загружает конфиг, собирает симуляцию через `SimulationStarter`, запускает инициализацию и выполнение.
- `SimulationStarter` — связывает зависимости (конфиг, остров, фабрики, сервисы) и создает экземпляр `SimulationEngine`.

## Пакет `config`

- `AnimalConfig` — DTO с параметрами конкретного вида: вес, лимит на клетку, скорость, потребность в пище.
- `Configuration` — агрегирует всю загруженную конфигурацию: настройки острова, симуляции, параметры видов, таблицы питания, приплод.
- `IslandConfig` — размеры острова (`width`, `height`).
- `LoadConfig` — загрузка и парсинг YAML в объект `Configuration` (с проверкой обязательных полей).
- `SimulationConfig` — общие параметры симуляции: длительность тика, лимит тиков, размер пулов, рост растений и т.д.
- `AnimalType` (enum) — список всех типов существ/растений и маппинг ключей YAML.

## Пакет `model`

- `Island` — двумерная сетка локаций, доступ к клеткам, проверка границ, обход всех точек.
- `Island.LocationPoint` — служебный контейнер координат и ссылки на локацию.
- `Location` — состояние одной клетки: списки животных и растений, операции добавления/удаления, снапшоты и подсчеты.

## Пакет `entity`

- `Animal` — базовый абстрактный класс животного: хранение состояния (сытость, жив/мертв), базовая логика `eat/move/reproduce/dead`.
- `AnimalActionContext` — контекст действия животного в текущем тике (остров, клетка, координаты, тик, конфиг, фабрика).
- `AnimalFactory` — создание конкретного класса животного по `AnimalType`.
- `AnimalTypeResolver` — определяет `AnimalType` по экземпляру животного.
- `Plant` — модель растения (вес растения как источник пищи).

## Пакет `entity.predators`

- `PredatorAnimal` — абстрактная база для хищников.
- `Wolf` — модель волка.
- `Boa` — модель удава.
- `Fox` — модель лисы.
- `Bear` — модель медведя.
- `Eagle` — модель орла.

## Пакет `entity.vegetarians`

- `VegetarianAnimal` — абстрактная база для травоядных.
- `Horse` — модель лошади.
- `Deer` — модель оленя.
- `Rabbit` — модель кролика.
- `Mouse` — модель мыши.
- `Goat` — модель козы.
- `Sheep` — модель овцы.
- `Boar` — модель кабана.
- `Buffalo` — модель буйвола.
- `Duck` — модель утки.
- `Caterpillar` — модель гусеницы.

## Пакет `entity.actions`

- `Eat` — маркерный интерфейс действия питания.
- `Reproduction` — маркерный интерфейс действия размножения.
- `SelectMove` — маркерный интерфейс действия перемещения.

## Пакет `simulation`

- `SimulationEngine` — оркестратор симуляции: scheduled-задачи (рост растений, жизненный цикл, статистика), условия остановки, управление пулами.
- `AnimalLifecycleProcessor` — выполняет жизненный цикл животных по фазам (`eat -> move -> reproduce -> death`) и параллелит обработку по диапазонам клеток.
- `WorldInitializer` — стартовая инициализация мира: заселение животных по клеткам, старт растений, рост растений на тике.
- `FeedingService` — запускает фазу питания животных по диапазону клеток.
- `MovementService` — запускает фазу перемещения животных по диапазону клеток.
- `ReproductionService` — запускает фазу размножения животных по диапазону клеток.
- `DeathService` — запускает фазу обновления голода/смерти и чистки мертвых по диапазону клеток.
- `StatisticsService` — собирает и печатает статистику по видам/растениям и считает общее число живых животных.

## Пакет `util`

- `Randomizer` — заготовка для утилит случайности (сейчас пустой класс).
